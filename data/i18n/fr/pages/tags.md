    tooltip: "Rust est un langage de programmation sans garbage collector, qui garantit la **sécurité mémoire à la compilation** grâce à l'ownership et au borrowing.   - tag: Python
    tooltip: "Python est un langage interprété reconnu pour sa **lisibilité** et son **écosystème massif**. Il est couramment utilisé pour le scripting, l'automatisation, la data science et le prototypage rapide plutôt que pour la performance brute."
  - tag: SQLite
    tooltip: "SQLite est un moteur de base de données SQL **léger**, **sans serveur** et **basé sur un fichier**. Il ne nécessite aucun processus serveur séparé, ce qui en fait un choix idéal pour le stockage embarqué dans des outils, des applications mobiles et de petits jeux de données locaux."
  - tag: React
    tooltip: "React est une bibliothèque JavaScript pour construire des **interfaces utilisateur** à partir de composants réutilisables. C'est l'un des outils front-end les plus largement adoptés sur le web."

  - tag: Coding
